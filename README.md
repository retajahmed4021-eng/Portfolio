# Retaj Ahmed Zaki: Portfolio

React + Vite + Tailwind CSS (v3) + Lucide icons.

    npm install
    npm run dev      # local dev server
    npm run build    # production build in /dist

## Editing
- All text, links, projects and contact details: `src/data/content.js`
- Project screenshots: put images in `public/` and set `image: '/your-file.png'`
- Add `liveUrl` / `githubUrl` / contact `value` + `href` to activate buttons and links
- Colors and fonts: `tailwind.config.js`
